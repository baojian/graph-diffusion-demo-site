# 图上的动态扩散

[打开互动演示](https://baojian.github.io/graph-diffusion-demo-site/)

从单个节点出发，观察热量沿图的边传播。可以切换两个社区、网格和环，
选择起点，播放或拖动时间轴，并调整社区间的桥。
默认采用持续热源和增强颜色对比，稳定后源点附近仍然较热；
也可以切换单次释放，观察自由扩散趋于均匀。

所有 HTML、CSS 和 JavaScript 均在 `index.html` 内，无外部运行时依赖。
下载这个文件后，可以直接用浏览器离线打开。

此仓库是公开网页的发布副本，通过 GitHub Pages 从 `main` 根目录发布。
